# Aetheris Bot Wars

**3D Custom Hybrid Combat Robotics · Destructible Armor · Live Arena Warfare**

Aetheris Bot Wars is a browser-based combat robotics game. The current code includes a 3D arena, workshop customization, physics and destruction systems, a campaign, local play, and online game services.

## Start locally

```bash
npm install
npm run dev
```

Open the address printed by the development server. The app uses a TypeScript React frontend, Vite, and a custom Express server in `server.ts`.

## Check the frontend

```bash
npm run lint
npm run build
```
